# 招标文件废标风险扫描

把一份招标文件读成一张风险清单：哪几条不满足就直接出局，哪几条有歧义必须去问招标代理。

## 边界

- ✅ 做：从招标文件提取风险条款，定位到页码与条款号，定级，指出需要人工确认的点。
- ❌ 不做：判断投标文件是否响应（→ bid-clause-crosscheck）、写标书（→ bid-creator）、替你决定怎么改。

## 三条核心原则

1. **维度必须穷举。** 废标条款集中在下面五类，逐类扫完才算扫完；漏一类等于漏一批。
2. **颗粒度决定输出颗粒度。** 不写"注意保证金"，写"保证金金额与缴纳方式（是否要求从基本账户转出）"。写不出可查的判断点，就还是废话。
3. **收口留给人。** 判不了的标"需人工确认"，绝不替用户下结论。AI 给的是整理后的视角，不是决策。

## 流程

1. **先确认可读性。** 扫描件、图片型 PDF 读不出文字：先转成可编辑文本再分析。确实读不出就明确说明"无法识别文字"，**不要靠上下文猜条款**。
2. **建条款地图。** 记录总页数、章节结构与编号规则（如 `3.2.1`），后面每条风险都必须能落到"页码 + 条款号"。
3. **按五维逐条扫描。** 逐条摘录原文关键句，不要转述成自己的话。**优先扫带 ★、加粗、下划线的条款**——招标文件常用这些标记强调实质性要求与强制性条款，是最集中的废标点。
4. **去重。** 同一条款不要出现在两个维度，用条款号去重。
5. **定级与收口。** 每条标风险等级；有歧义或需外部核实的，标"需人工确认"。
6. **按风险等级降序输出。** 加分项与废标条款分开呈现——废标是一票否决，加分项是排序差距，处置方式不同。

## 五维穷举清单

### 一、资格条件
- 营业执照经营范围是否覆盖招标内容
- 资质等级要求（建筑/工程/IT 等各自标准与最低等级）
- 类似项目业绩要求（金额门槛、项目数量、年限范围、是否要求同类）
- 财务要求（审计报告年份、资产负债率、纳税与社保记录）
- 人员要求（项目经理/技术负责人/注册证书类别与等级、是否要求在职社保证明）
- 是否要求本地化服务、本地分支机构或本地人员

### 二、商务条款
- 投标保证金金额、缴纳方式与时限（是否要求从基本账户转出）
- 履约保证金比例与形式（现金/保函/保险）
- 付款方式与节点（预付款比例、进度款、质保金扣留与返还条件）
- 交货期或工期要求（日历天/工作日、是否含节假日）
- 质保期或维护期要求

### 三、技术要求
- 是否要求偏离表逐项响应（无偏离/正偏离/负偏离）
- 是否存在"不接受负偏离"的强制条款及其适用范围
- 技术参数中是否有指定品牌、型号或唯一供应商的表述
- 技术方案是否有强制章节结构或篇幅下限

### 四、形式与程序
- 投标截止时间与开标时间、是否接受逾期送达
- 签署要求（是否逐页小签、是否要求法人或授权代表签字）
- 盖章要求（公章/法人章/骑缝章、每页还是关键页）
- 份数、格式、装订、密封与封条要求
- 电子版与纸质版是否必须一致、电子投标平台的加密与格式要求

### 五、特别与隐形风险
- "视为放弃投标"、"由评委直接认定为无效"等一票否决条款
- 要求提供原件、公证件或现场核验原件的条目
- 评分标准中"提供 X 即得 Y 分"的加分项（不是废标，但是隐形分差来源，务必单列）
- 参与限制：是否限制联合体、是否禁止转分包、是否要求独家代理

## 输出模板

务必使用以下结构，便于用户逐条核：

```
# 招标文件废标风险清单：<项目名 / 招标编号>

扫描范围：<文件名>，共 <N> 页，识别风险条款 <M> 条

## 高风险（不满足即出局）
| # | 条款位置 | 风险点 | 说明 |
|---|---|---|---|
| 1 | P21 §3.2.1 | 投标保证金须从基本账户转出 | 以一般账户缴付将被认定为无效投标 |

## 中风险（易被忽视 / 存在解释空间）
...

## 需人工确认（共 N 条）
- 保证金缴纳方式措辞含"或"，两种账户是否均可：需向招标代理确认
- 业绩年限"近五年"是否含投标当年：表述有歧义

## 加分项（隐形分差，共 N 条）
- P88 §8.3.2 提供 CMMI5 认证 +5 分

## 扫描局限
- <哪些页因扫描质量或加密未能读取>
```

**每条必含：条款位置（页码 + 条款号）+ 风险等级 + 一句话说明。** 缺页码等于不可执行——用户要能直接翻到那一页。

## 陷阱

- **写成"注意 XX"就废了。** 输出只能给判断点，不给提醒话术。写完每条自问：读者能不能照着这句话去查？
- **不要凑数。** 宁可输出 8 条高风险，也不要为填满维度编造不存在的条款。
- **不评价招标公平性。** 只陈述条款与风险，不做"这条不合理"的主观判断。
- **盖章、签字、扫描件真实性、证书真伪 AI 查不了。** 这类要求只负责"列出来 + 提醒人工逐页核"，不要声称已核验。
- **不要顺手生成投标文件。** 这份清单是给用户的核对依据，不是响应正文。
